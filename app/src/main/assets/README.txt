# 원본에는 상·하행 두 행이 똑같은 좌표인 쉼터가 16곳(32행) 있었다:
#   탄부·일죽·번천·도척·소초·당진·서천·태령·주암·광양·고성·김해·창원·곤양·수동·일광
# 이 32행만 오픈스트리트맵(© OpenStreetMap contributors, ODbL) 도로 기하로 보정했다.
#   1) api.openstreetmap.org(0.6 map)에서 쉼터 둘레 고속도로의 일방통행 차로 두 개와 각 진행 방향을 읽는다.
#   2) ‘도로노선방향’(A기점 + B종점 = B 쪽으로 가는 차로)을 B 도시 쪽으로 향하는 차로에 맞춘다(A·B 위치는 OSM Nominatim).
#   3) 그 차로 위 가장 가까운 점에서 진행 방향 오른쪽으로 20m(쉼터가 있는 바깥쪽) 옮긴 점을 새 좌표로 쓴다.
#   도척은 중부·제2중부 차로 넷이 나란히 있어 데이터의 노선(중부선)인 중부고속도로 차로만 썼다.
#   일광은 원본 좌표가 부산외곽순환고속도로에서 1.2km 떨어져 있어 OSM ‘일광졸음쉼터’(35.2814328, 129.2065787) 기준으로 잡았다.
# 이 좌표는 진입로 위치를 실측한 값이 아니라 ‘어느 차로의 쉼터인지’를 맞춘 근삿값이다. 좌표만으로 내비가 해당 차로로 안내한다고 보장할 수 없다.
# 실제 진입 경로 확인이 필요하며, 정확한 진입 지점은 수십 m 다를 수 있다. 원본을 새로 받을 때는 위 방법으로 다시 보정하거나, 공공데이터포털에 정정을 요청한다.
# 그 뒤 나머지 221행 전부를 OSM 고속도로와의 거리로 점검했다(2026-11-14). 218행은 고속도로에서 150m 안이었고, 아래 3행만 벗어나 고쳤다.
#   성남(서울외곽선): 원본 좌표가 주택가(고속도로에서 약 1.1km) → OSM ‘성남졸음쉼터’(37.4355698, 127.1239401)
#   적금(영동선) 2행: 한 행이 고속도로에서 약 1km → OSM ‘적금졸음쉼터’ 두 곳(인천 방향 37.2530157, 127.7041233 / 강릉 방향 37.2525698, 127.7038332)
